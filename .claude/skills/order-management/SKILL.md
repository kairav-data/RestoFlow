# Order Management

Order lifecycle:

CREATED
→ ACCEPTED
→ PREPARING
→ READY
→ SERVED
→ COMPLETED

Possible cancellation:

CREATED
→ CANCELLED

Owner/staff must be able to see:

Table
Customer/session
Items
Quantity
Modifiers
Notes
Amount
Status
Time

Customer sees simplified status.

Owner sees operational detail.
