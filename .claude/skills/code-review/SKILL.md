# Code Review

Check:

Architecture
TypeScript
Security
Tenant isolation
Performance
Accessibility
Responsive behavior
Component reuse
Error handling
Loading states
Empty states
Testing

Look for:

duplicate code
giant components
any types
unsafe queries
client-side secrets
missing authorization
poor mobile UX

Do not rewrite everything.

Report:

Critical
High
Medium
Low

Then propose targeted fixes.
