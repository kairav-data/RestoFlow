# RestoFlow Design System

## Brand

Primary brand:

Premium white and red hospitality aesthetic (the Tailwind `amber` scale is mapped to the brand red).

Core visual language:

- Crisp white surfaces
- Deep charcoal
- Brand red (#C8202F) as the single accent
- Soft neutral gray
- Muted green
- Soft blue
- Soft purple for AI

Do not use extremely saturated colors.

---

## Typography

Use a modern sans-serif.

Recommended:

Inter or Geist.

Headings:

Strong but elegant.

Body:

Highly readable.

Avoid excessive font weights.

---

## Border Radius

Use consistent radius levels:

sm: 8px
md: 12px
lg: 16px
xl: 20px

Do not randomly mix radius values.

---

## Spacing

Use a consistent spacing system.

Prefer:

4
8
12
16
24
32
48
64

---

## Cards

Cards should:

- Have clear hierarchy
- Use subtle borders
- Use restrained shadows
- Avoid excessive decoration

---

## Icons

Use Lucide icons.

Do not use random icon libraries.

Do not use emoji as interface icons.

---

## Charts

Charts must communicate something meaningful.

Every chart should have:

- title
- timeframe
- legend where needed
- tooltip
- empty state

Avoid unnecessary chart decoration.

---

## Animation

Use Framer Motion for meaningful interactions.

Animation should be:

- subtle
- fast
- purposeful

Avoid distracting animations.

---

## Customer UI

Mobile UI should feel:

- warm
- premium
- photographic
- inviting

---

## Owner UI

Owner dashboard should feel:

- analytical
- professional
- calm
- information-rich

but never cluttered.
