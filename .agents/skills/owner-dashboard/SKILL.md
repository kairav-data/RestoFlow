# Owner Dashboard

Owner dashboard is desktop-first.

The first screen should answer:

What is happening today?

Prioritize:

Revenue
Orders
Customers
Average Order Value
Rating
Live Orders

Then:

Customer insights
Menu performance
Feedback
Peak hours
Dining duration
Popular combinations

Charts must lead to decisions.

Prefer:

"What happened?"
"Why?"
"What should I investigate?"

Avoid charts without meaning.
